6. 确认后再次同步，检查已同步/pending=0、最近成功时间和云端摘要；在测试仓库查看 `data/state.json` 及提交记录，确认没有 Token/本机 outbox/设备授权。

API 证据只记录状态码、目标、提交/文件 SHA、是否条件命中和时间，不记录 Authorization、完整请求头、Token 或私人正文。若需读开发者工具，请先隐藏凭证输入和敏感面板。没有遇到真实限流就记录「模拟覆盖，真实未触发」。

## 失败时反馈

提供页面名称、点击顺序、在线/离线、屏幕可见的固定错误、刷新前后记录数量及复现是否稳定。可反馈 GitHub Actions 链接、HTTP 状态和人工记录的事件 UUID；隐藏 Token、请求头、个人备份及无关仓库。暂停有风险的重复写入，先保留本机完整 JSON，再按 [故障手册](SYNC_TROUBLESHOOTING.md) 处理。
