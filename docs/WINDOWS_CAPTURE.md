# Windows 划词与收词

## 安装与启动

目标 Windows 10/11 x64；本轮实际运行平台为 Windows 11 build 26200，Windows 10 尚未实测。产物为 `artifacts/desktop/Polar-Vocab-Capture-0.4.0-win-x64.exe`，便携运行，无需安装服务或管理员权限。程序未签名；SmartScreen 的提示及兼容性可能因机器而异，不要全局关闭系统安全保护。首次启动只注册快捷键和托盘，不开启自动上传或自启动。

开发者从根目录执行 `npm ci`、`npm run desktop:dev`。生产构建用 `npm run desktop:package`；完整环境见 [DEVELOPMENT](DEVELOPMENT.md)。

## 选词与收藏

1. 在普通文本应用中选中人工测试文字，按默认 **Ctrl+Alt+S**。设置可更换组合，注册失败时明确提示。
2. 选择英语或德语。默认自动请求 MyMemory 中文候选；可取消、手动查询或直接填写。
3. 核对或修改中文释义、词性、原句、标签及来源；德语可填冠词、复数、过去式、第二分词，均可为空。
4. 选择完整原句时可按「将当前原文作为原句」，再将原词改成所需单词；只选一个词不会自动取得上下文。
5. 点击「收藏到生词队列」或在单行输入框按 Enter。只有本机 SQLite 事务成功才显示已收藏；重复点击不会为同一草稿创建第二个事件。
6. Esc、关闭按钮或「仅查看，关闭」隐藏窗口，不收藏。系统托盘可重开；明确「退出并释放快捷键」才结束后台进程。

未收藏编辑存在时，新选词只显示提示，用户决定切换或保留。保存失败保留编辑；已保存事件不可在队列中直接修改，正式整理在 Web 完成。主动点击「新词」代表新的采集，允许有意多次收藏同一拼写，Web 会提示相似词。

默认语言偏好在下次启动时使用；当前会话可直接切换「查询语言」。主题可以立即预览，点击保存才持久保存。

## 选区兼容性与剪贴板

优先通过 Windows UI Automation 的 TextPattern 读取当前选区；无安全结果时才考虑复制回退。它不是 OCR，也不监听所有复制操作。密码字段、UIA超时或焦点无法确认时直接手动输入。

复制回退只接受空剪贴板或可完整保存的 Windows 原始纯文本格式（CF_TEXT、CF_OEMTEXT、CF_UNICODETEXT、CF_LOCALE），每格式最多1 MiB。遇到图片、HTML、RTF、自定义格式时不模拟复制，不声称能够无损恢复这些格式；如果 UIA 可直接读取则仍可选词且不碰剪贴板。

模拟 Ctrl+C 前后检查剪贴板序列号、前台窗口及复制所有者，等待异步复制并检查超时。没有新复制结果时不会使用旧剪贴板文字；恢复前再次检查序列号，不覆盖其他程序随后写入的内容。剪贴板管理器可能导致安全回退失效，此时手动粘贴。浏览器、Word、PDF、VS Code 等不能仅因理论支持就标记为已适配；逐项实测状态见 [报告](../reports/phase-4/PHASE4_REPORT.md)。

## 翻译供应商

当前 Provider Adapter 为 **MyMemory / Translated**，只调用文档公开的匿名 GET `/get`；语言对 `en|zh-CN` 与 `de|zh-CN`。无 API Key、无邮箱、无付费计划，也不调用语料贡献 `/set`。免费匿名约5,000字符/日，单次最多500个UTF-8字节；服务可变更配额或中断。

原文会发送至供应商，供应商条款允许处理/保留提交内容并使用合作翻译服务。不要查询敏感内容。其他原句字段、标签、本机队列与 GitHub PAT 不随查询发送。请求10秒超时，可取消；网络失败、额度不足、非中文候选均提示人工填写，不猜词形。

实际请求曾对 `Haus` 返回错误的 `mini`，已保留记录并增加非中文候选拒绝；这只能拦截明显异常，不能保证中文候选语义正确。必要时补充短语、换语言或手动编辑。

依据：[API](https://mymemory.translated.net/doc/spec.php)、[额度](https://mymemory.translated.net/doc/usagelimits.php)、[条款](https://mymemory.translated.net/terms-and-conditions)。

## 本机队列与离线

默认数据目录为 `%APPDATA%\Polar Vocab Capture\`，设置页显示实际位置。程序不在可执行文件旁保存词库。

- `captures.sqlite`、`captures.sqlite-wal`、`captures.sqlite-shm`：事务队列及非敏感偏好/目标信息。
- `logs/events.log`：固定事件分类及时间，不记录选词、释义、Token或原始错误堆栈。
- 状态：待上传、正在上传、已确认上传、上传失败、需要处理。支持搜索、筛选、分页、重试与完整 JSON 导出。

离线收藏不依赖翻译或 GitHub。上传失败保留事件 UUID 与冻结批次；联网后重新授权并手动同步。导出不含Token，仍可能含私人词汇，应妥善保存。导出不覆盖同名文件。查看「已确认上传」只表示云端批次已存在，不表示 Web 已接收。

## GitHub 与 Web 接收

仅用人工测试目标 `Polar0216/polar-vocab-data-test` / `main`。使用已有仍有效或自行创建的有限期 Fine-grained PAT，Only select repositories 仅选该私库，Contents 读写、Metadata 默认只读；不需要每次新建，不要发送Token。本轮用户已暂缓真实私库实测，以下为以后主动恢复时的操作说明。

桌面设置填写 owner/repo/branch/PAT → 测试连接（只读）→ 核对私有目标 → 确认连接。凭证输入框随测试清空，主进程仅当前会话内存使用。退出需重新授权；取消预检会清除该预检凭证。默认不开启自动同步，可手动同步或显式开启有限自动重试（自动尝试至少间隔一分钟，每次最多10批、连续失败3次暂停）。

上传路径 `captures/{deviceId}/{YYYY-MM}/{batchId}.json`，不写 `data/state.json`。冻结批次绑定原目标，不能把未确认的旧批次改投另一仓库。断开连接保留队列，已有云端文件不删除。

正式站已部署 Phase 4 接收入口：生词箱 → 接收桌面生词 → 检查批次 → 选择并预览 → 按语言/词形筛选 → 确认接收。新词默认待整理，原文及来源保留，相似词默认不勾选。重复事件按既有回执跳过，不覆盖人工修改；随后在 Web 用原有同步引擎同步正式词库。这些行为已有模拟测试；真实私库采集全链路仍未验证，详细状态以报告为准。

## 退出、移除与保留

关闭窗口隐藏至托盘；退出会注销快捷键、取消查询与上传，不删除队列。便携版无卸载器，退出后移除 exe 不影响 `%APPDATA%` 数据。不要只在程序运行时复制单独的 SQLite 主文件；先用导出功能备份，或完全退出后一起保留队列文件。数据删除/云端归档尚未提供，本阶段不清理历史测试环境。
