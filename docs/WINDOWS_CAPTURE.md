# Windows 划词与收词（Capture 0.6.1）

本机日常入口现位于外层 `polar-vocab/启动Capture收词.lnk`，工程已整体收进同层的 `project/`；桌面旧入口收回history，不再保留桌面图标。完整背词用外层“打开背词软件.url”。便携程序解压目录属于临时运行目录，不应作为日常快捷方式目标。若旧版本仍在后台，打开新版只会唤回旧进程；应先用应用内“退出并释放快捷键”或托盘退出，关闭主窗只会隐藏。旧程序和队列继续保留。

## 启动和正式目录

日常使用整合便携程序 `artifacts/desktop/current/Polar-Vocab-Capture-0.6.1-win-x64.exe`，无需隔离启动器、管理员权限或后台服务。程序未签名，SmartScreen和兼容性因机器而异，不要全局关闭系统安全保护。目标Windows10/11 x64，本轮环境为Windows11；Windows10尚未实测。实际生成、校验值和运行状态以[最新整理与同步验收](../reports/integrated/CLEANUP_AND_LIVE_ACCEPTANCE_20261027.md)为准；历史结果见[整合报告](../reports/integrated/INTEGRATED_RELEASE_REPORT.md)。

1. 先在旧版托盘选「退出并释放快捷键」；关闭旧窗口只隐藏，可能仍占用Ctrl+Alt+S。旧exe及队列继续保留。
2. 双击新版exe。首次使用默认不开启自动上传或开机自启动，窗口关闭后驻留托盘。
3. 在设置核对版本、实际数据目录和「当前注册：成功」。快捷键占用时仍可手动查词，可更换组合并保存；不要通过删除旧数据解决占用。

正式数据固定为 `%APPDATA%\Polar Vocab\Capture`，不在exe旁保存词库：

| 位置 | 内容 |
| --- | --- |
| `captures.sqlite`及存在的WAL/SHM | 原事件、状态、冻结批次、回执、无Token的目标及偏好 |
| `migration-backups/` | 迁移源在线快照、清单和回滚证据 |
| `logs/events.log` | 固定事件类别及时间，不含原文、释义或Token |
| `logs/performance.jsonl` | 划词反馈、原生读取等阶段的固定类别及耗时 |
| `logs/query-performance.jsonl` | 词典/翻译阶段耗时，与窗口可见耗时分开 |
| 同级 `Capture.runtime/` | Electron/Chromium缓存，与队列迁移目标分开 |

本轮明确选定旧0.5.0人工候选空队列迁入正式目录：0事件、0批次，版本1→2，设备身份与设置保留，原源和在线备份均保留。旧默认`%APPDATA%\Polar Vocab Capture`没有数据库，因此不声称已迁入未知旧词或复习记录，也没有合并全部测试目录。其他独立旧源仅可在新版空库通过「从旧队列迁入（仅空库）」显式选择；详见[迁移与回滚](INTEGRATED_MIGRATION.md)。

开发者从根目录执行`npm ci`、`npm run desktop:dev`；保留旧产物的独立输出打包见[DEVELOPMENT](DEVELOPMENT.md)。`POLAR_VOCAB_CAPTURE_DATA_DIR`仅供内部开发测试，日常不用配置。不要让旧程序打开v2新版数据库，也不要让新版原地覆盖旧v1目录。

## 划词、词典和收藏

1. 在原应用选中明确允许查询的文字，按 **Ctrl+Alt+S**。先出现非激活反馈，读取完成后显示编辑窗口；不会让词典或网络请求阻塞反馈。无法自动取词时可直接输入或粘贴。
2. 选英语/德语，并核对自动建议的单词、短语或整句模式；识别有误可手动切换。
3. 单词模式查询WiktApi词典：每条义项独立显示词性、原文释义、可用例句和中文候选，可新增、删除和编辑。中文由独立MyMemory提供，不以机器翻译冒充词典原文。
4. 出现明确词形关系时，核对原始词形和原型候选；有歧义需选择，不从词尾猜测。德语冠词、复数和变位只有明确数据或人工填写时保存，缺失留空。
5. 点击「收藏到生词队列」，或在单词模式主输入框按Enter。SQLite事务成功后才显示已收藏，同一草稿重复点击不新建第二事件。
6. Esc或关闭按钮仅隐藏且不收藏；托盘可重开。选择「退出并释放快捷键」才结束后台进程。

未收藏编辑存在时，新选区只提示，由本人决定切换或保留。保存失败保留编辑；旧查询不得覆盖新草稿或手改内容。已收藏事件不可在队列中直接改写，正式整理在Web完成。主动「新词」属于新采集，可有意收藏相同拼写，Web会提示相似词。

## 整句翻译与句中选词

原文按原顺序保留Unicode字符、空格和标点；可点击词片段作为收藏目标。先看到原文，再等待独立句译；翻译失败不关闭窗口，仍可手动改中文、选词和收藏。

- 句译最多5,000字符、40个分段请求，每段不超过500 UTF-8字节，并发最多2个，总截止30秒。超限会提示，不截断词制造成功结果。
- 用户只明确请求所选文本，不自动抓取未选中上下文；手动输入不逐字联网。关闭「允许外部查询」后仍可离线编辑和收藏。
- 点击句中词后，收藏目标lemma与原始遇到词形分开，词典明确的原型关系及来源保留。多个词可复用原句context ID，每个事件仍带完整原句，不依赖外部云记录。
- 中文句译默认不随收藏保留；核对并勾选后才保存译文、语言和来源。部分失败结果先补齐再保留，编辑原句会取消旧译文的关联。

实际公开服务已验证6个指定英德词形关系，真实打包应用的人工整句MyMemory请求本轮记录为1390ms。这只是该次翻译网络完成时间，**不是快捷键响应时间**。本轮原生跨应用快捷键计时未完成，不宣称200–300ms目标已达成；完整边界见整合报告与[文本流程](INTEGRATED_TEXT_FLOW.md)。

## 原生选区与剪贴板保护

优先使用Windows UI Automation TextPattern读取当前选区；这是明确快捷键请求，不是OCR、全局输入监听或持续剪贴板监听。密码字段、焦点无法确认和原生超时均回退到手动输入；反馈窗口不激活原应用焦点，读取完成后才聚焦主表单。

复制回退只接受空剪贴板或可完整保留的原始纯文本格式（CF_TEXT、CF_OEMTEXT、CF_UNICODETEXT、CF_LOCALE），每格式最多1MiB。图片、HTML、RTF及自定义格式不模拟复制；UIA直接成功则无需碰剪贴板。

模拟Ctrl+C前后核对前台窗口、剪贴板序列号及复制所有者，没有新结果不会用旧剪贴板文字；恢复前再次检查序列号，不覆盖其他程序之后的写入。剪贴板管理器可能令安全回退失败，此时手动粘贴。不得因理论支持就声称Word、浏览器、PDF或VSCode已全面适配，实际跨应用结果逐项记录。

0.4.1的非激活反馈、常驻原生broker、繁忙状态管理和结构化日志已整合保留。旧性能证据见[原修复报告](../reports/phase-4/HOTKEY_PERFORMANCE_FIX_2026-10-26.md)，新版本的当前原生焦点/快捷键未测项不追记为通过。

## Provider与内容来源

词典使用免Key WiktApi提供的英语Wiktionary数据，英语及德语释义、词性、词形和例句按实际返回保存。Wiktionary内容及改写保留来源/许可；没有打包音频或自动复制quotation。没有查到的字段留空。

中文义项和整句使用MyMemory匿名GET接口，语言对`en|zh-CN`或`de|zh-CN`。无需Key、邮箱或付费计划，不调用语料贡献接口；匿名免费约5,000字符/日、每请求500 UTF-8字节，服务可能中断或调整限制。单次请求原有10秒超时，整句另有30秒总预算。

原文会交给供应商处理，条款可能允许保留及合作方处理；不要查询敏感文本。只发送明确待查文本，不附加其他原句字段、标签、队列或GitHub PAT。中文候选需核对，非中文异常拦截不能保证语义正确。

来源、许可和费用说明见[DICTIONARY_PROVIDERS](DICTIONARY_PROVIDERS.md)；真实服务与模拟夹具在报告中分别列出。

## 离线队列、授权和Web接收

离线收藏不依赖词典、翻译或GitHub。状态包含待上传、上传中、已确认上传、失败、需要处理，支持搜索、筛选、分页、重试和JSON导出。导出不含Token但可能含私人词汇，应保存在私人位置；不会覆盖同名文件。「已确认上传」仅表示云端批次存在，不代表Web已接收。

本轮真实验收仅对`Polar0216/polar-vocab-data-test / main`人工数据。设置填写owner/repo/branch，点「输入凭证并测试（系统窗口）」，在本应用原生密码框本人输入受限Fine-grained PAT：只选该私库，Contents读写、Metadata默认只读、有限有效期。不得发到聊天，也不复用以前贴在聊天中的凭证。

只读预检后核对目标再确认，可明确勾选「记住此设备」。PAT只由主进程使用，选择记住时保存在当前用户Windows Credential Manager，不进React、SQLite、备份或日志。重开异步只读复验；网络暂不可用保留，已保存授权401失效，断开忘记后停止自动恢复。详见[安全授权](INTEGRATED_AUTH.md)。

所有桌面上传入口还需在线确认正式站`release.json`具备协议1/2和当前上下文能力。未确认暂停上传，队列和原冻结批次保留；先发布兼容Web再上传，不凭源码测试推定正式站已兼容。默认手动同步，可显式开启有限自动批量重试。

只创建`captures/{deviceId}/{YYYY-MM}/{batchId}.json`，不写`data/state.json`；原冻结批次不能改投其他仓库。Web生词箱→接收桌面生词→检查/选择/预览→明确接收，新词待整理、不自动建卡；同事件回执去重，不覆盖人工修改，再由原Web同步引擎写主快照。旧事件协议1继续可读，新结构化/词形/句译事件使用协议2，FSRS算法、评分身份和原采集UUIDv5保持。

本轮模拟Web全回归37通过/3跳过，桌面回归6通过/2跳过；真实公开Provider另有通过记录。模拟GitHub和安全存储测试不能代替真实私库上传与Web接收；最终发布、真实远端及未完成项目见整合报告，不进行iOS验收。

## 退出与历史保留

退出会释放快捷键、取消查询与内存上传会话，不删除队列；曾明确记住的Windows凭证保留至断开或失效。移除exe不会删除AppData。活跃SQLite不能只复制主文件冒充完整备份，应使用导出或SQLite在线备份；不删除WAL/SHM、改事件ID或重建批次。

0.4.0、0.4.1、0.5.0程序、隔离候选目录和旧报告均继续保留，不需要清理才能使用新版。0.5.0的独立启动器、当时尚未更新公开Web及禁止上传限制是该阶段历史，不是0.6.0日常启动方式；旧目录中的迁移快照不会追随之后的写入，切换后避免继续向旧版收藏而形成两套待同步。
