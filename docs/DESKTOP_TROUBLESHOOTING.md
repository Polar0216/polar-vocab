# Windows 收词故障排查

| 现象 | 检查与保留方式 |
| --- | --- |
| 快捷键无响应 | 打开托盘→设置核对注册结果。组合被占用时换一个组合并保存；管理员或安全桌面不在适配范围。 |
| 出现手动输入提示 | UIA未取得安全选区或超时，或剪贴板存在图片/富文本。手动输入/粘贴，不必清空原剪贴板。 |
| 旧剪贴板没有被导入 | 正常保护：没有新序列号/所有者验证成功时不会把旧内容当选区。 |
| 富文本/剪贴板管理器阻止回退 | 复制回退只支持有限原始纯文本格式；关闭回退可只用UIA，或手动粘贴。没有无损全格式恢复承诺。 |
| 长选区无法查询 | 选区最大500字符；翻译API另限制500 UTF-8字节。缩短原文或手动填写，程序不会静默截断。 |
| 德语翻译错误或不是中文 | 免费翻译记忆候选可能错误；程序拒绝明显非中文候选，中文结果仍需人工核对。补充短语、切换语言、手动编辑；不要猜冠词/复数。 |
| 翻译超时/取消/无网络 | 查询10秒超时；本地收藏仍可用。原句、释义手动填后保存，不会上传未收藏内容。 |
| 收藏失败 | 保留当前编辑，检查磁盘/目录权限。不要删除 SQLite 重建。设置显示实际目录；先导出或退出后备份完整目录。 |
| 显示需要处理 | 内容碰撞、协议不合法或权限禁止。保留原批次和队列，导出备份后查目标/权限；不要给原事件换UUID来掩盖冲突。 |
| 重启后未授权 | Token只在进程内存中。输入新的或仍有效的受限PAT并预检确认，原队列不会丢失。 |
| 401/403/404 | 核对Token有效期、指定仓库、Contents读写、目标Private和分支。不要把错误响应/凭证发到聊天，记录界面固定错误即可。404不自动初始化主库。 |
| 已上传但Web看不到 | 确认Web已发布Phase4接收入口，连接同一目标与分支，在生词箱检查/预览/确认；桌面ACK不是Web摄取回执。 |
| Web提示列表截断/预算超出 | 停止并保留资料，不能当作空队列或完整列表，也不能通过删历史规避。后续需正式分片设计。 |
| 退出后似乎仍运行 | ×只是隐藏到托盘；选择「退出并释放快捷键」。不以强制结束进程作为日常退出方法。 |
| 未签名程序出现系统提示 | 本版未购买签名证书，不能承诺无SmartScreen。核对来源/文件哈希，不要全局关闭安全保护。 |
| native助手或启动失败 | Windows x64、.NET Framework 4.x以及 `SelectionHelper.exe` 必须完整。保留原数据；查看仅固定分类的日志，不发送私人队列。 |

默认数据 `%APPDATA%\Polar Vocab Capture\`，实际位置以设置为准；开发验收使用独立 `.cache/phase4-real-*` 配置。`logs/events.log` 不包含选词/Token，但文件时间仍可能反映使用行为。便携版删除不删除本机数据。

自动测试输出可重复生成，真实验收资料和Phase3.5历史不自动清理。当前未验证项见 [报告](../reports/phase-4/PHASE4_REPORT.md)，不要为获得「全通过」重置私库或复习记录。
